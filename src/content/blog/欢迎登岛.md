这里是雾岛。第一盏灯，点亮了。

这个博客是给"写下来"这件事用的：技术笔记、生活随笔，以及一些没想清楚的事。它由 Typora + Astro + Cloudflare Pages 驱动，写作流程只有三步：

1. 在 Typora 里写 Markdown，图片放 `./media/文章名/`
2. 跑 `npm run publish -- 文章名` 发布
3. `git push`，自动构建上线

## 一段代码

```js
const island = {
  name: '雾岛',

};
```
