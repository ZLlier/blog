第一篇写的是《GIT入门》，这一篇讲讲这个博客本身是怎么从零到上线的——既包括"网页部署和域名"的原理，也包括它具体的技术实现。写完它，也算是对这两周折腾的一个交代。

## 一次发布，背后发生了什么

```
Typora 写 md → publish 脚本 → git push
    → GitHub 存代码（Webhook 通知 Cloudflare）
    → Cloudflare 自动 clone → npm install → npm run build
    → dist 传到全球边缘节点
    → 读者访问 wudaoblog.top → DNS 解析 → 最近节点返回 HTML
```

五个环节，每个都说清楚：

**① 构建（Build）**：浏览器只认 HTML，不认 Markdown。构建就是翻译——Astro 读取 `content/blog/*.md`，套上模板和样式，翻译成一个个静态 `.html` 文件。静态网站 = 纯文件集合，不需要服务器实时计算，所以便宜、快、不用数据库，最适合博客。

**② 代码仓库（GitHub）**：存源文件和历史版本。中间隔这一层，是因为代码是资产：托管商可以换，代码跟着你走；GitHub 免费替你备份，还能看到每次改了什么。

**③ 自动部署（CI/CD）**：原理叫 Webhook。你 `git push` 之后，GitHub 主动通知 Cloudflare"有更新"，Cloudflare 自己动手：克隆仓库 → 装依赖 → 构建 → 把产物传上边缘节点。全程不需要你碰服务器——这就是"push 即上线"。

**④ 域名与 DNS**：域名只是一串字符，DNS 是把它翻译成服务器 IP 的电话簿。DNS 是分层的：浏览器先问 `.top` 顶级服务器"wudaoblog.top 归谁管"，顶级服务器答"归 Cloudflare 的 NS 管"，再问 Cloudflare 拿到 IP。**NS 记录 = 电话簿出版权**——我们把 NS 从腾讯云（DNSPod）改给 Cloudflare，解析权就移交了。为什么必须移交？因为 HTTPS 证书的自动签发和 Worker 绑定的自动 CNAME，都要求 Cloudflare 能证明"域名归你"。

**⑤ HTTPS 证书**：浏览器小锁头 = 网站身份证 + 加密传输。Cloudflare 掌控解析权后可以自己给自己证明，免费自动签发，所以你全程没看到"配置证书"这步。

## 这个博客的技术实现

**技术栈**：Astro 7.2.1 + Node 24，内容是一个 Markdown 文件夹，托管在 Cloudflare Workers（新版统一平台，构建时自动加 `@astrojs/cloudflare` 适配器）。

**内容加载器（最折腾的部分）**：Astro 7 的内容集合支持自定义 loader，我写了一个，做三件事：

- 解析 frontmatter（`title` / `date` / `tags` 三个字段，**全部可缺省**）
- 缺失时回退派生：没 `title` 取正文第一个 `#` 标题，没 `date` 取文件修改时间，没 `tags` 留空——所以旧笔记不用补元数据也能直接发
- 跳过空文件（有篇 0 字节的旧笔记就是这么被挡住的）

**图片管线**：Typora 的图片存在 `./media/文章名/` 里，md 里是相对路径。两个零件解决：一个 remark 插件把 `./media/x` 重写为 `/media/x`（只在 AST 层面处理真正的图片节点，不会误伤代码块）；一个 Astro 集成在构建前把 `media/` 文件夹复制到 `public/`。文章和图片永远在一起。

**代码高亮**：Shiki 双主题（白天 github-light / 夜间 github-dark），通过 CSS 变量切换——Astro 7 不再自动切换，需要自己补一条 `[data-theme='dark']` 的规则。

**日夜切换**：`<html data-theme>` 属性 + localStorage 记忆，首帧前内联脚本防止闪烁，全站 CSS 变量换肤。

**发布脚本**：`npm run publish -- 文章名`——把 md 和它的 `media/` 文件夹一起复制进 content（防"只发文字漏图"）、自动补 frontmatter、日期用本地时区（UTC 会差 8 小时，踩过）。

**dev 体验**：自定义 loader 在 dev 模式下监听内容目录变化，新增/修改/删除文章页面自动刷新，不用重启服务器。

## 踩过的坑

- **`*.workers.dev` 在国内打不开**：GFW 对这个域名段做 SNI 层拦截 + DNS 污染，连直接问 Cloudflare 权威服务器都被劫持（三个 NS 返回三个假 IP）。部署本身全球正常（check-host 四国节点全 200），换自定义域名就通了
- **Astro 7 API 变动大**：自定义 loader 是对象形态（`{ name, load }`）、markdown 插件要显式用 `unified()`、渲染函数从 `entry.render()` 变成了 `render()`——照着 7 的文档写，别信 5 的教程
- **npm 官方源在国内会卡死**：换 npmmirror 镜像，2 分钟装完
- **开发工具条只有英文**：Astro dev 模式右下角的悬浮工具条（Audit/Inspect 那些）没有中文，对博客也没用，直接 `devToolbar: { enabled: false }` 关掉

## 写作流程（现在的日常）

```bash
cd D:\Mine\Code\Zcode\Blog
npm run publish -- 文章名     # 发布：带图 + 自动补 frontmatter
git add . && git commit -m "发布：文章名" && git push   # 上线
```

写新文章时顶部加三行 frontmatter 更规范（不加也行，自动回退）：

```markdown
---
title: 文章标题
date: 2026-08-14
tags:
  - 折腾
---
```
